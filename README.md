# 🤖 AI Study Assistant

An AI-powered study assistant built with Python, Google Gemini and Streamlit.

## 🚀 Try the Live App

[Open AI Study Assistant](https://ai-study-assistant.streamlit.app)

## ✨ Features

- 📝 Create study notes
- 🧠 Generate quizzes
- 🎴 Generate flashcards
- 💬 Ask AI study questions
- 📊 Study dashboard

## 🛠️ Technologies

- Python
- Streamlit
- Google Gemini
- GitHub
